# 真机环境 RGB 相机标定

> **当前状态与结果见 [RGBCAL_SUMMARY.md](RGBCAL_SUMMARY.md)。**当前环境相机是 Logitech C920
> （`--profile c920`）；下文「本机实测结论」是第一轮**笔记本自带摄像头**的历史结果，仅作记录。
> 命令的完整列表以 `bash LLM-control/run_rgbcal.sh --help` 为准。

针对**物理 SO101** 的环境相机标定。与 `nexus_vision` 的仿真相机完全分开：这里没有任何数值来自
MuJoCo，焦距、畸变、位姿和桌面高度一律实测，并且和「在什么成像配置下测的」绑定保存。

入口：[run_rgbcal.sh](run_rgbcal.sh)，独立环境 `.venv-rgbcal`（OpenCV 5，含 `aruco`、Qt 窗口），
不改动锁定的 `.venv-loop`。

```bash
# 建环境（只需一次）
uv venv --python 3.12 LLM-control/.venv-rgbcal
uv pip install --python LLM-control/.venv-rgbcal/bin/python opencv-contrib-python "numpy<3"
```

## 命令

| 命令 | 作用 |
| --- | --- |
| `devices` | 列出所有 V4L2 节点、USB 身份、占用进程，区分笔记本自带和外接腕部相机 |
| `modes` | 实测驱动真正给出的分辨率（不是标称值） |
| `snap` | 无窗口抓帧，保存原图和完整相机设置 |
| `preview` | 第一阶段：实时机位检查，HUD 显示分辨率／帧率／时间戳／清晰度／曝光，`--labels` 按顺序命名每一张 |
| `mirror-check` | 用 ArUco 判定画面是否被水平镜像（普通棋盘格页无标记，必须用 ChArUco 页） |
| `inspect` | 对已保存的图做量化：棋盘检出、px/mm、边缘余量、曝光，`--colour red` 量彩色物体像素尺寸 |
| `lock` | 第一阶段收尾：记录已确认的机位、设备身份、相机设置和背景锚点 |
| `check-setup` | 对比锚点，判断相机是否被碰动（位移 > 3 px 必须重测外参） |
| `collect` | 第二阶段：内参样本采集，实时判定可用性并在拍摄当下分配验证集 |
| `solve` | 拟合 `K`、`D`，输出逐图误差、整体 RMS 和平面性残差 |
| `verify` | 独立验证：留出集误差、径向误差分布、标定板直角检查、去畸变前后对比图 |

所有原始图片写入后**不再修改、不被覆盖**（重名直接报错）。图片一律按驱动输出保存，不旋转、不镜像、
不裁剪、不缩放；任何变换都写在 `image_transform` 里显式声明。

## 本机实测结论（2026-09-17）

### 设备

| 项 | 值 |
| --- | --- |
| 环境相机 | `/dev/video0`，`Integrated Camera`，USB `5986:118a`（笔记本自带） |
| 腕部相机 | `/dev/video2`，`USB2.0_CAM1`，USB `05a3:9230`（**本次未标定**） |
| 采集配置 | 1280 × 720，MJPG，驱动 30 fps，实测约 20.8 fps |
| 对焦 | 驱动报 `autofocus=-1`，定焦，无对焦漂移 |
| 镜像 | **无镜像**。ArUco 实测：原样帧解出 23 个码，水平翻转后 1 个 |
| 最高分辨率 | 1280 × 720（请求 1080p 会被驱动降回 720p） |
| 4:3 模式 | 水平视野窄约 21%，垂直只多约 6%，**不用** |

### 第一阶段：机位（已锁定，见 `calib/setup-01/`）

侧面斜视，能同时看到桌面和物体侧面。实测：

- 25 mm 方块在工作区五个位置为 **67 × 69 ~ 99 × 96 px**；
- 近端物体离画面下边缘 **72 px**（10% 余量线），远端余量 95–137 px；
- 抬升到堆叠最高点时夹爪牙完整在画面内，上方余量约 130 px；
- 曝光高光裁剪 0.0%，清晰度 200+；棋盘格在工作区各处 54/54 检出。

**已知限制**：抬升时腕部以上的手臂会被上边缘切掉。定位和完成验证需要的夹爪牙与物体都在画面内，
但**不能用环境相机判断整条手臂姿态**，那要看关节角度。

### 第二阶段：内参（`calib/intrinsics-02/`）

```
fx 982.17   fy 981.78   cx 633.67   cy 376.96      (1280 x 720)
D  [0.16312, -0.59354, 0.00125, -0.00024, 0.61273]  (k1,k2,p1,p2,k3)
视场角 水平 66.18°   垂直 40.27°
```

| 检查 | 结果 |
| --- | --- |
| 标定集重投影 RMS（20 张） | **0.297 px**，最差 0.478 px |
| **留出验证集 RMS（5 张）** | **0.244 px**，最差 0.271 px |
| 径向误差分布（验证集，5 段） | 0.195 ~ 0.260 px，**边缘不劣于中心** |
| 标定板直角检查（与打印尺寸无关） | 角度误差中位数 0.14°，最大 0.20° |
| 平面性残差（去畸变后单应） | 中位数 0.229 px |
| 覆盖半径 | 观测到 660 px / 画面角点 748 px（**88%**） |

验证集在**拍摄当下**按固定规则（每第 5 张）分配，在任何误差算出来之前就定好，不可能事后挑选。

**模型选择有实测依据**：standard（5 系数）验证 RMS 0.244，rational 0.247，thin-prism 0.260。
参数更多反而让留出集变差，所以用 standard。

**两条限制**：

1. **半径 660 px 以外（画面四角）的畸变是外推的**，本报告的误差数字不覆盖那里。工作区实际落在
   半径 236–501 px，在已验证范围内。
2. **格长 25.0 mm 是打印标称值，未用尺子实测**。它不影响 `K` 和 `D`，只线性缩放第三阶段的米制
   外参，事后可用一个标量修正，无需重拍。

### 失败记录（保留不删）

`calib/intrinsics-01/` 是第一次采集：标定纸手持、纸面弯曲，重投影 RMS **2.545 px**，`cx` 偏离
画面中心 91 px，切向系数虚高。去畸变后的单应残差中位数 1.72 px 暴露了原因——弯曲的板子被算法
当成了镜头畸变。把纸贴到硬板上重拍后残差降到 0.23 px。采集工具已加入 `flatness` 实时判定
（阈值 2.0 px）防止再次发生。

## 什么情况下需要重新标定

| 变化 | 内参 `K`/`D` | 外参 `T_base_camera` |
| --- | --- | --- |
| 移动笔记本、改变屏幕开合角度 | 不需要 | **必须重测** |
| 移动机械臂底座或桌面 | 不需要 | **必须重测** |
| 改分辨率、像素格式、裁剪、旋转、镜像 | **必须重做** | 必须重测 |
| 换一台/一颗摄像头 | **必须重做** | 必须重测 |
| 只是灯光、曝光、白平衡变化 | 不需要 | 不需要 |
| 实测出打印缩放系数 | 不需要 | 用标量修正即可 |

相机是否被碰动用 `check-setup` 客观判定，不靠肉眼。
